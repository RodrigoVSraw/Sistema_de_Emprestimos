# ***Projeto de Engenharia de Software - Sistema de Empréstimos***

Este projeto foi feito com intuito de treinar minhas habilidades de engenharia de software, na qual fiz diversos planejamentos e etapas da construção de software,
usando **Caso de Uso Expandido**, **Modelo Conceitual**, **Diagrama de Eventos** e por fim **Contratos**.

As classes e métodos deste sistema foram construídas a partir de um planejamento estruturada antes de ir para o código.

## **Funcionalidades**

- **Registro de Empréstimos:** Adiciona um registro de empréstimo entre um credor e devedor que fazem parte do sistema.
- **Quitar Empréstimos:** Permite que o usuário quite um empréstimo.
- **Consultar Situação de Usuário:** Consulta todos os empréstimos, na qual o usuário é credor e devedor, assim mostrando seu crédito e débito totais.
- **Alteração de Senha do Usuário:** Altera a senha de um usuário já cadastrado no sistema, após confirmar sua senha atual.
